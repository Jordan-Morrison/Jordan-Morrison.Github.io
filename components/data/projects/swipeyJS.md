[Swipey.js](https://www.npmjs.com/package/swipey.js) is a lightweight JavaScript library I designed, developed and published to NPM to make adding swipe gestures to web applications simple and flexible. At just 1.29 KB with zero dependencies, the library works with both Vanilla JavaScript and React while providing configurable support for horizontal, vertical and diagonal gestures. Developing the package involved creating a straightforward API, handling touch interactions and gesture detection, and packaging the library for easy integration across different projects.
