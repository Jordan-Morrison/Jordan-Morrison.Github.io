[React Child Lock](https://www.npmjs.com/package/react-child-lock) is a lightweight React component I designed, developed and published to NPM to provide a simple way of restricting access to websites while they are under development. Built with reusability and customization in mind, the package allows developers to quickly add a configurable lock screen to a React project without building the functionality from scratch. Developing the package involved designing a flexible component API, packaging it for use across different projects and maintaining it as a publicly available open-source dependency.
